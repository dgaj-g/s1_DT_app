## Source Basis

Local extracted sources show repeated mark-scheme wording for resolution:

- 2018 Q4(a)(ii): resolution can be described as image quality, pixels per inch, or number of pixels; higher resolution improves quality and requires more storage.
- 2019 Q4(a)(ii): resolution can be described as the number of pixels in an image or pixels per inch; more pixels means better quality.
- 2023 Q2(b): higher resolution means larger image/file size; more pixels means larger file/image size.

The 24-bit true-colour count item is mathematically accurate, but it is too niche for this revision bank and not representative of the past-paper questioning pattern being prioritised.
