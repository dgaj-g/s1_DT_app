# Stage 4 Objective Mapping Framework

This document defines the first-pass learning-objective framework used during
Stage 4 content import for the Unit 1 revision app.

It exists for one reason: the app cannot offer meaningful topic stats,
objective-level weakness detection, or reliable adaptive support if imported
questions only carry a topic label. We need a second layer beneath the topic.

## Current Progress Snapshot

Latest verified run against the real Unit 1 source pack:

- 904 questions processed
- 856 questions mapped to one or more objective codes
- 48 questions still left flagged `needs_objective_mapping`

That is deliberate. The mapper should reduce manual workload sharply without
pretending to know more than the evidence supports.

## Design Principles

The objective mapper should:

- stay close to the CCEA / fact-file structure
- prefer honest partial automation over overconfident misclassification
- map questions to one or two strong objective codes, not a long fuzzy list
- leave genuinely unclear cases for later review rather than forcing a weak tag
- give later stats/adaptive logic a consistent and reviewable structure

## How The Mapper Works

The current first-pass mapper is heuristic rather than AI-driven.

It scores objective definitions within the question's topic using evidence from:

- the question stem
- the answer / mark-scheme text
- list-block labels and items
- figure captions
- source locator text
- question-type label
- basic tags generated by the importer

A question receives:

- the strongest-scoring objective code
- and optionally a second objective code if it is also strongly supported

If no objective has enough evidence, the question is intentionally left
unmapped so it can still be flagged for review.

## Important Accuracy Note

This mapping framework is a first-pass enrichment layer. It should reduce the
number of unclassified questions dramatically, but it should not be treated as
final QA sign-off on curriculum alignment by itself.

Questions can still need review because of:

- transformed past-paper wording
- ambiguous overlap between two objectives
- weak or missing teaching explanations
- auto-marking rules that still need tightening

## Next Quality Steps After Objective Mapping

1. inspect unmapped questions topic by topic
2. refine keyword rules where the misses are legitimate and repeated
3. tighten explanation enrichment using fact-file language and mark-scheme intent
4. review high-risk transformed questions before anything is promoted live
