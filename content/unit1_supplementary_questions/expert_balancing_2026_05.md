### Q1 [3 marks] - Multiple Choice

[Source: supplementary expert balancing item based on cloud computing advantages and disadvantages]

A school is deciding whether to move shared files and applications from its own local server to a cloud provider. Which option gives the best balanced reason for using cloud computing?

A. It removes the need for any internet connection and guarantees no security risk.
B. It can reduce local hardware costs and allow access from different locations, but it depends on a reliable internet connection.
C. It means all files are stored only on each user's device and cannot be shared.
D. It prevents staff from collaborating because files are no longer held on a local server.

**Answer:** B

---

### Q2 [3 marks] - Multiple Choice

[Source: supplementary expert balancing item based on cloud connectivity risks]

A business uses cloud software for its booking system. The office internet connection fails during the day. Which consequence is most likely?

A. Staff may be unable to access the booking system until connectivity is restored.
B. The cloud provider automatically turns the booking system into local software.
C. The business no longer needs backups because the internet has failed.
D. The booking data is converted into a spreadsheet macro.

**Answer:** A

---

### Q3 [3 marks] - Multiple Choice

A. The game is streamed or downloaded in parts so the user can begin before all files are stored locally.
B. The game must be copied to a DVD before any part can run.
C. The game can run without any processor, memory or network connection.
D. The game is stored as a bitmap image so it needs less bandwidth.

[Source: supplementary expert balancing item based on cloud file sharing and collaboration]

### Q5 [3 marks] - Multiple Choice

[Source: supplementary expert balancing item based on cloud storage and organisational impact]
